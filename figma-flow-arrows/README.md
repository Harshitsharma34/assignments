# Scoins flow arrows (Figma plugin)

Adds gold flow arrows to the "Scoins screens" page of the Scoins Figma file.

1. Open the file in the Figma desktop app.
2. Menu → Plugins → Development → Import plugin from manifest… → pick `manifest.json` in this folder.
3. Menu → Plugins → Development → Scoins flow arrows.

It is safe to run again: it removes arrows from a previous run first.
