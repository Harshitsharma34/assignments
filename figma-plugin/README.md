# Scoins screens → Figma

Creates a page called **Scoins screens** in any Figma file, with one section per flow
(Wallet, Wallet sheets, Intro animation, Earn, Spend flow, Withdraw flow) and one named
390-pt frame per screen. Screens are embedded as 2× images.

1. Open the Figma **desktop app** and any design file (or a new one).
2. Menu → **Plugins → Development → Import plugin from manifest…**
3. Choose `manifest.json` in this folder.
4. Menu → **Plugins → Development → Scoins screens**. It takes a few seconds.

To place the images by hand instead, drag the PNGs from `docs/case-study/screens/` onto the canvas.
